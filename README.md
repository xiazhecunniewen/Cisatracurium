# Cisatracurium
Semi-untethered jailbreak for iOS 17.1+ and will support iOS 9.0-17.1 soon
# Usage
Sideload the ipa, and download any 网路（天津）电子商务有限公司‘s app except 网路优行 (114网路叫车，网路出行，网路聚合司机端has removed from App Store so if you want to use them for jailbreaking you need to download them from History Download page) in App Store.
## Must download form App Store !!! (Notice that only Chinese Region Account has these app)
Open the Cisatracurium app, and choose your 网路app and which Sileo version you want to install, and press jailbreak button(ignore our rubbish UI) and set your sudo password and wait for the jailbreak success.
